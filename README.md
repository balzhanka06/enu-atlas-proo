# ENU ATLAS PRO — GitHub Pages

ENU Smart Campus картасы: Leaflet + OpenStreetMap, іздеу, ғимарат/жатақхана карточкалары, маршрут интерфейсі, GeoJSON импорт, таңдаулылар, тақырып ауыстыру, Campus Assistant.

## GitHub-та жариялау
1. GitHub-та **enu-atlas-pro** атты Public репозиторий ашыңыз.
2. Осы папканың **ішіндегі барлық файлдарды**, оның ішінде `.github` және `.nojekyll` файлдарын репозиторийдің **түбіріне** жүктеңіз.
3. Репозиторийде `main` branch таңдаңыз.
4. Settings → Pages → Build and deployment → Source: **GitHub Actions**.
5. Actions бөлімінде Deploy ENU ATLAS орындалғанын күтіңіз. Мекенжай: `https://USERNAME.github.io/enu-atlas-pro/` (USERNAME орнына өз GitHub логиніңізді жазыңыз).

## Жергілікті тексеру
`python -m http.server 8000`, кейін `http://localhost:8000`.

## QGIS-тегі 182 маршрутты қосу
QGIS-та маршруттарды EPSG:4326 GeoJSON форматына экспорттаңыз. Сайттағы GeoJSON импорттау интерфейсінен таңдаңыз. 182 маршруттың нақты деректері бұл пакетке енгізілмеген; браузерде импортталуы маршруттың өріс құрылымына байланысты. Интернет пен сыртқы маршрут қызметі қолжетімсіз болса, маршрут есептеу шектелуі мүмкін.

## Шектеулер
- Бұл GitHub Pages-ке дайын **статикалық frontend**, жеке серверлік backend жоқ.
- Ғимарат координаттары мен қабаттар — бұрынғы GIS жобасының деректері; ресми тексерілген толық indoor жоспарлар емес.
- Campus Assistant — ережелерге негізделген, нақты LLM емес.
- Бұл пакет GitHub-қа автоматты түрде жүктелмеген және жария домен әлі берілмеген.
- Leaflet және карта тайлдары үшін интернет керек.
